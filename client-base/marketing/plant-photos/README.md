# Your real plant photos → poster

Save **3 photos** here (from your phone). Use these exact filenames:

| File | Plant label on poster |
|------|------------------------|
| `pengpengxiang.jpg` | 碰碰香 |
| `biyu.jpg` | 碧玉 |
| `jinyuhua.jpg` | 金魚花 |

Formats: `.jpg`, `.png`, or `.webp` also work.

Then run:

```bash
cd client-base/marketing
python3 compose_plant_mockup_poster.py
```

Output: **`plant-mockup-poster.png`** (your real pictures, enhanced, no PP logo editing needed if you crop it out of the photo first).

**Tip:** Pick one clear photo per plant type. Crop close to the glass cup if possible.
