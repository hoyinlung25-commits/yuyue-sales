# Poster fonts

`WenQuanYiMicroHei.ttc` is bundled so posters render Traditional Chinese on any machine.

Regenerate posters from `client-base/marketing/`:

```bash
python3 compose_bupa_vtop_poster.py
```

Optional: add `NotoSansTC-Regular.otf` and `NotoSansTC-Bold.otf` here; scripts prefer those if present.
