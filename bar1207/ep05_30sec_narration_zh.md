# EP05 — 30 秒中文旁白 · 勇者找勇氣

**角色：** 遥斗 蓮 · 遙かの王国嘅勇者  
**形式：** 第一人稱內心獨白 · 哲思 · 故事交代  
**時長：** ~28–32 秒  

---

## 粵語版（推薦）

```
我十六歲嗰陣，人哋叫我勇者——
去殺龍，人人都信我可以。

上星期，天燒起。劍斷咗。同伴冇返嚟。
村里仍然舉旗，仍然叫我勇者。
得我一個知：勇氣，唔喺度了。

唔係冇希望咁簡單——
係唔知，点样再企起身。

雨巷有扇冇招牌嘅门。
入面时鐘停喺十二點七分。
唔迟唔早，刚好喺中间——
好似留低一个位，畀我搵返样嘢。

喺度，唔使赢。
唔使扮作仲系英雄。
我只系……搵勇氣。

十二時七分。勇者找勇氣。
```

---

## 普通話版

```
我十六岁那年，人们叫我勇者——
去杀龙，人人都信我可以。

上星期，天烧起来。剑断了。同伴没有回来。
村里仍然举旗，仍然叫我勇者。
只有我知道：勇气，不在身上了。

不是没有希望那么简单——
是不知道，怎样再站起来。

雨巷有一扇没有招牌的门。
里面时钟停在十二点七分。
不迟不早，刚好在中间——
好像留下一个位置，让我找回一样东西。

在这里，不必赢。
不必假装还是英雄。
我只是……找勇气。

十二时七分。勇者找勇气。
```
