# EP04 — 30 秒中文內心獨白（哲思 · 故事版）

**角色：** Clara Webb · 2017 wellness 文案撰稿人 · 24 歲  
**形式：** **第一人稱內心獨白** — 佢對自己講，唔係旁白介紹佢  
**時長：** 約 28–32 秒 · **語氣：** 靜、慢、近 · 似腦內低語，唔似講道  

---

## 粵語版（推薦）

### 內心獨白正文

```
我替冥想 App 写咗咁多句——
「吸气，平靜；呼气，放鬆。」
写畀几百万人跟住做。
但我关咗屏幕……
个头入面，仲亮着。

我以为平静系订阅制。
十日试用，月费，Annual Plan。
原来心唔会同你开发票。
佢只问我：
我而家喺唔喺度？
定系……演习紧「喺度」？

雨夜，我行入一条地图冇嘅巷。
一扇冇招牌嘅门。
入面时计停喺十二时七分——
唔迟，唔早。
好似世界留低一个位，畀我停。

冇导师，冇剧本，冇人叫我进步。
我唔再用力搵张菜单——
先Feel到，原来有六道菜，一直喺度。

我冇变成更好嘅人。
我只系……终于喺度。
呢样，已经够矜贵。
```

## 普通話版（國語備選）

### 内心独白正文

```
我给冥想 App 写了那么多句——
「吸气，平静；呼气，放松。」
写给几百万人跟着做。
但我关了屏幕……
脑子里面，还亮着。

我以为平静是一种订阅。
十天试用，月费，年费。
原来心不会给你开发票。
它只问我：
我现在在不在？
还是……在演习「在」？

雨夜，我走进一条地图上没有的巷。
一扇没有招牌的门。
里面时钟停在十二点七分——
不迟，不早。
好像世界留下一个位置，给我停。

没有导师，没有剧本，没有人叫我进步。
我不再用力找那张菜单——
才感觉到，原来有六道菜，一直在。

我没有变成更好的人。
我只是……终于在了。
这样，已经够珍贵。
```

## 內心獨白 vs 旁白 · 點樣讀

| | ❌ 旁白（唔要） | ✅ 內心獨白（要） |
|---|----------------|------------------|
| 人稱 | 佢替 App 写文案 | **我**替 App 写文案 |
| 距離 | 講故事畀觀眾聽 | **自己對自己講** |
| 語氣 | 纪录片、解説 | 腦內低語、近麥、有停頓 |
| 停頓 | 每句完整 | 「但我关咗屏幕……」後 **留空** |
| 問句 | 佢只问 | **佢只问我** — 問自己 |

## 加長版內心獨白（約 45 秒 · 可選）

**粵語：**
```
我系 Clara。
伦敦来，香港写冥想。
我写过二百条引导——教人呼吸，教人放下。
但从来冇人教过我：关咗屏幕之后，点样令个头熄灯。

今晚我唔再试。
我搵到扇门。
十二时七分。
Still Point、Breath、Time、Emptiness、Light、Rest——
六道菜，我唔读，我Feel。

我唔使自己变好。
我只系，第一次，喺度。
```

**普通話：**
```
我是 Clara。
从伦敦来，在香港写冥想。
我写过二百条引导——教人呼吸，教人放下。
但从来没人教过我：关了屏幕之后，怎么让脑子熄灯。

今晚我不再试。
我找到一扇门。
十二点七分。
Still Point、Breath、Time、Emptiness、Light、Rest——
六道菜，我不读，我感受。

我不逼自己变好。
我只是，第一次，在了。
```
