## 視覺定義

| 項目 | v3 規格 |
|------|---------|
| **媒介感** | 鋼筆／原子筆在**畫紙**上畫出來（非數位平塗向量） |
| **畫紙** | 暖米色 `#F2EBD9`，可見紙紋、輕微纖維質感 |
| **線條** | 墨色 `#2A2420`，**略歪、略抖**，線寬約 2.5–3px，有輕重 |
| **上色** | 淡薰衣草**水彩暈染** `#E8D8E8`（opacity ~55%），不是實心向量填色 |
| **眼與嘴** | **永久鎖定** → [`axo-face-locked-zh-TW.md`](./axo-face-locked-zh-TW.md) |
| **官方主檔** | `png/axo-pen-canonical.png`（空白思考雲 + 下方小 Axo + **鎖定臉**） |
| **修改方式** | 以主檔為 reference **只改指定部位**（如只縮眼、只加思考雲），禁止整張換風格 |
| **腮紅** | 不要 |
| **頭身** | 三頭身 |
| **情緒** | Stupid cute、呆、心酸療癒（與瑞秋廖／呱鬆蛙蛙同溫層） |

## 與 rachelliao_illustration 對齊

- 手繪線條 > 完美幾何  
- 畫紙底色 > 純白去背感  
- 角色小、**情緒一句話**大（IG 4:5）  
- 可愛但不日系萌、不 3D、不厚塗
