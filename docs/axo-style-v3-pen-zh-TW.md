# Axo 繪畫風格 v3 — 鋼筆手繪 × 畫紙

**更新：** 2026-06-01 · **主參考：** [@rachelliao_illustration](https://www.instagram.com/rachelliao_illustration/) Reels／手繪筆觸  

**取代：** v2 純平面向量為**次要**；對外 IG 以 **v3 手繪畫紙** 為主。

---

## 視覺定義

| 項目 | v3 規格 |
|------|---------|
| **媒介感** | 鋼筆／原子筆在**畫紙**上畫出來（非數位平塗向量） |
| **畫紙** | 暖米色 `#F2EBD9`，可見紙紋、輕微纖維質感 |
| **線條** | 墨色 `#2A2420`，**略歪、略抖**，線寬約 2.5–3px，有輕重 |
| **上色** | 淡薰衣草**水彩暈染** `#E8D8E8`（opacity ~55%），不是實心向量填色 |
| **眼睛** | 仍為兩顆**手畫黑點**（可略不圓，更像筆點） |
| **嘴巴** | 極小 **`w`**，一筆畫成 |
| **腮紅** | 不要 |
| **頭身** | 三頭身 |
| **情緒** | Stupid cute、呆、心酸療癒（與瑞秋廖／呱鬆蛙蛙同溫層） |

---

## 與 rachelliao_illustration 對齊

- 手繪線條 > 完美幾何  
- 畫紙底色 > 純白去背感  
- 角色小、**情緒一句話**大（IG 4:5）  
- 可愛但不日系萌、不 3D、不厚塗
