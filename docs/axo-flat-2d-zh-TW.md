# Axo 必須是「平面手繪」— 禁止立體感

**參考真源：** 品牌方提供的標準立姿圖（細線鋼筆 + 色鉛筆質感、**完全 2D 平塗**）

---

## 為什麼會變「立體」？

| 錯誤做法 | 視覺結果 |
|----------|----------|
| 多層**實心橢圓**疊在身體上 | 像 3D 球體 / 向量吉祥物 |
| **漸層、陰影、投影** | 數位立體、不夠手繪 |
| 窗戶**實心色塊**當玻璃 | 有景深的插畫感 |
| AI 關鍵字 `3D` `render` `Cute mascot` | 常出立體萌系 |

---

## 正確效果（與參考圖一致）

- **2D 平面**：只有線稿 + 色鉛筆**排線／斜線筆觸**填色  
- **線條**：細、略歪、一筆一筆（約 2–2.5px）  
- **上色**：淡薰衣草 `#D4BEE0`～`#E8D8E8`，可見筆觸、**不要**光滑漸層  
- **陰影**：僅腳下幾條**淡交叉線**（可選），其餘不加  
- **禁止**：腮紅、高光、厚塗、CGI、立體建模感  

---

## 出圖流程

1. 以 `axo-pen-canonical.svg` 的**線條與筆觸**為準，只改姿勢／道具  
2. SVG 用 `pattern` 斜線模擬色鉛筆，**不要**多顆半透明橢圓堆體積  
3. AI 提示必含：`flat 2D hand-drawn sketch, colored pencil texture on paper`  
4. AI 提示**禁止**：`3D`, `render`, `CGI`, `gradient`, `shading`, `volumetric`, `glossy`
