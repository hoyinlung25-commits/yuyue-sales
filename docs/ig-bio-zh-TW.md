## Bio 撰寫原則

1. **第一句** = 你是誰 / 給什麼（休息、共感）  
2. **第二句** = Axo 人設（呆、空、可愛）  
3. **可選** = emo 也 welcome（拉深層粉絲）  
4. **Hashtag 不放 Bio**（放貼文就好）  
5. **🫠** 一個就够（品牌表情）
