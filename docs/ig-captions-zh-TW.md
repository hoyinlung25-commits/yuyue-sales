## Post 1 — 介紹 Axo（首發）

### 繁中 Caption（複製用）

```
這是 Axo。

一隻站在地上、常常發呆的墨西哥鈍口螈。
眼睛很小，心情很空，但沒有惡意。

我是 Dozeify。
我們相信：休息不是偷懶，是充電。
如果你今天也什麼都不想做——
你可以在這裡一起什麼都不做。

歡迎認識 Axo。🫠

—

#Dozeify #Axo #再生式休息 #墨西哥鈍口螈 #發呆也可以 #療癒漫畫 #什麼都沒做
```

### English（可放在留言置頂或第二段）

```
This is Axo — a tiny axolotl who stands on two legs and zones out a lot.
Small eyes. Empty head. Zero harm.

Dozeify is about regenerative rest:
doing nothing is still something.

Glad you're here. 🫠
```

- 投票：「你今天有在發呆嗎？」→ 有 / 正在

## 發文小提醒

| 項目 | 建議 |
|------|------|
| 第一篇 | 不要放連結、不要提衣服 |
| 第二篇 | 延續第一篇語氣，當「認識 Axo 之後的第一個日常」 |
| 留言 | 第一篇結尾可問：「你們想幫 Axo 取暱稱嗎？」拉互動 |
| 回覆語氣 | 短、呆、真誠，例：「Axo 說：嗯。」 |
