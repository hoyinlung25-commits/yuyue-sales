## Post 1 — 介紹 Axo（首發）

### 繁中 Caption（複製用）

```
這是 Axo。

一隻站在地上、常常發呆的墨西哥鈍口螈。
眼睛很小，心情很空，但沒有惡意。

我是 Dozeify。
我們相信：休息不是偷懶，是充電。
如果你今天也什麼都不想做——
你可以在這裡一起什麼都不做。

歡迎認識 Axo。🫠

—

#Dozeify #Axo #再生式休息 #墨西哥鈍口螈 #發呆也可以 #療癒漫畫 #什麼都沒做
```

### English（可放在留言置頂或第二段）

```
This is Axo — a tiny axolotl who stands on two legs and zones out a lot.
Small eyes. Empty head. Zero harm.

Dozeify is about regenerative rest:
doing nothing is still something.

Glad you're here. 🫠
```

### 限動（Stories）建議

- 投票：「你今天有在發呆嗎？」→ 有 / 正在  
- 貼紙：指到 Axo 大頭「這傢伙是誰」

## Post 2 — Axo 在發呆

### 繁中 Caption（複製用）

```
Axo 上方的雲，
是空的。

不是忘記想什麼，
是今天真的什麼都沒想。

如果你也盯著某個地方超過三分鐘，
什麼都沒做，什麼也沒想——
那你跟 Axo 是同類。

今天什麼都沒做，什麼也沒想。🫠

—

#Dozeify #Axo #發呆 #放空 #再生式休息 #今天什麼都沒做 #療癒漫畫
```

### English（可置頂留言）

```
The cloud above Axo is empty.

Not "forgot what to think."
Just… didn't think anything today.

I am doing nothing today, and thinking nothing. 🫠
```

### 限動（Stories）建議

- 問答箱：「你發呆時都在看哪裡？」  
- 投票：「你的思考雲裡有東西嗎？」→ 空的 / 有一點點
