# Axo 外鰓規格（頭上「六角」）

**六角 = 頭兩側外鰓共 6 支**（左 3 + 右 3），與 [`axo-pen-canonical.svg`](../assets/axo/pen/axo-pen-canonical.svg) 一致。

---

## 必守

| 項目 | 規格 |
|------|------|
| 數量 | **每側 3 支**，共 **6 支**（不可缺一支） |
| 造型 | 羽狀、略分叉的弧線（手繪鋼筆） |
| 色 | 較身體深的薰衣草描線；可淡紫水彩暈 |
| 站姿 | 外鰓向上／略向外展 |
| 趴睡 | 外鰓**放鬆下垂**，但 **6 支仍要畫全** |

## 禁止

- ❌ 每側只畫 1～2 支  
- ❌ 缺角、斷掉一半  
- ❌ 與標準立姿外鰓造型完全不同
