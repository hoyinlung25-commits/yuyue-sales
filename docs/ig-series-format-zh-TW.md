## 每張固定版型

```
┌─────────────────────────────┐
│ Day X          （左上手寫）  │
│      ........ 或 一句英文     │  ← 上中：梗／對白
│                             │
│         （留白）             │
│      [ 角色 / 道具 ]         │  ← 下 2/3
│      ～～～ 腳下淡排線       │
```

| 元素 | 規格 |
|------|------|
| 背景 | 畫紙 `#F2EBD9`、紙紋、**平面 2D** |
| 角色 | 與 `axo-pen-canonical.png` 同色鉛筆蠑螈 |

| 左上 | **Day 2** / **Day 3** … 細手寫 |
| 上中 | 英文一句或 `........` 沉默 |
| 輪播 | 每格各一張 PNG，**每張都標 Day X** |
