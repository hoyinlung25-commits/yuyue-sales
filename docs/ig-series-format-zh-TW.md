# Axo IG 系列 · 每日兩種 Slide 版型

每天 = **至少 2 種 slide**（可再加漫畫格）。情緒可 **happy** 或 **emo**，文案跟著換。

---

## Slide A · 文字主軸（你提供的 Day 4 樣張）

```
┌─────────────────────────────┐
│ Day X                       │
│ ─────                       │  ← 左上有底線
│                             │
│   大字主句（居中）           │
│   小字副句（居中、全小寫可）  │
│                             │
│                             │
│    [ 底部小線稿 Axo+道具 ]   │  ← 黑色細線、極小
└─────────────────────────────┘
```

| 元素 | 規格 |
|------|------|
| 比例 | **1:1**（1080×1080）建議 |
| 背景 | 畫紙 `#F2EBD9`、紙紋 |
| 主句 | 英文、手寫感、**大字** |
| 副句 | 較小、可全小寫、療癒／吐槽 |
| 底部圖 | **只黑線**小 doodle，不要大色塊角色 |
| 情緒 | 見下表 |

### 文字 Slide 檔案

| 天 | 檔案 | 情緒 | 主句 |
|----|------|------|------|
| 2 | `axo-pen-day2-text.png` | 😊 happy | Today I made a whole list. Thing one was enough. |
| 3 | `axo-pen-day3-text.png` | 😔 emo | Sometimes you type a whole paragraph. Then delete it. |
| 4 | `axo-pen-day4-text.png` | 😌 calm | Sometimes you just stare at each other. No words needed. |

## Slide B · 漫畫主視覺（色鉛筆 Axo）

```
┌─────────────────────────────┐
│ Day X          （左上）      │
│      一句梗 或 ........      │  ← 上中
│         （留白）             │
│      [ 大紫 Axo + 道具 ]     │  ← 色鉛筆 2D
└─────────────────────────────┘
```

| 元素 | 規格 |
|------|------|
| 比例 | 4:5（1080×1350） |
| 角色 | 薰衣草色鉛筆、與 canonical 一致 |
| 臉 | 小眼平嘴（鎖定） |

### 漫畫 Slide 檔案

| 天 | 檔案 | 上中 |
|----|------|------|
| 2-1 | `axo-pen-day2-slide1.png` | Today I will do many things. |
| 2-2 | `axo-pen-day2-slide2.png` | Thing 1: Nap. |
| 3 | `axo-pen-day3.png` | ........ + 空氣泡 |

## 情緒輪替（之後 Day 5–7）

| 類型 | 主句語氣 | 例 |
|------|----------|-----|
| **happy** | 荒謬可愛、自我接納 | 清單只做一件也 OK |
| **emo** | 空、說不出、累 | 刪掉整段訊息 |
| **calm** | 沉默、陪伴 | 不用說話的默契 |
