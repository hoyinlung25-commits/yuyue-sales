## 品牌關鍵詞

**Stupid cute · 呆 · 非常呆** — 心酸系、放空、不積極但療癒（Regenerative Rest）

---

## 已確認規格

| 項目 | 決定 |
|------|------|
| 線條 | **5px** 細線（精緻） |
| 頭身 | **三頭身** |
| 手 | **簡單手指**，可拿杯子（見 `axo-with-mug.svg`） |
| 尾巴 | **維持現狀** |
| 眼睛 | 黑點 **r=4.5**（更小、更呆） |
| 嘴巴 | 幾乎只用 **`w`**；極少數情境才用 `_` |
| 腮紅 | **完全不要** |
| 身體色 | **薰衣草粉** `#E4D4EA` |
| 場景色 | 黑白 + 粉 + **最多 1–2 輔色**（如毯子 `#E8E4F0`） |
| IG 構圖 | **全身小角色 + 大字對白** |
| 衣服印花 | **Phase 2 再決定**（Printfly 已暫停；現專注 IG） |
| 對白字 | **手寫毛筆感**（完稿由設計師替換 SVG 佔位字） |
| 漫畫格 | **不規則手繪格** |
