## 系列原則

1. 定位：**大人的童話**（dark gothic 2D cartoon，非兒童甜水彩）
2. 筆觸要重畫：粗墨線＋平塗黑影＋限色（不是同一張圖只調暗）
3. 每集一個原創道德主題與金句
4. Shorts 60–75 秒優先驗證
5. 固定說書老人框架，降低定裝成本
6. 上傳時依規則揭露 AI；強調原創敘事價值
