**僅在需要「發呆」視覺時使用，非每篇必備。**

```
┌─────────────────────────┐
│   空白思考雲（必空）      │
│   Axo 偏小在下方          │
└─────────────────────────┘
```

- 雲內：**無字、無 `...`**  
- 臉：與標準立姿**相同**（鎖定眼嘴）

---

## 如何做新的一篇

1. 預設從 **`axo-pen-canonical`** 出發  
2. Reference `axo-pen-canonical.png` + 鎖定臉  
3. 只改姿勢／場景；**色票**見 color-consistency 文件  
4. 若要發呆梗 → 改用 **B** 模板，不要強制每篇加雲
