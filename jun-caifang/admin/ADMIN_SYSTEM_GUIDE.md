# 俊才坊行政系統使用指南

## 檔案

| 檔案 | 說明 |
|------|------|
| `output/俊才坊行政系統.xlsx` | 完整行政系統（10 個工作表） |
| `google_apps_script.js` | Google Sheets 自動化腳本 |
| `build_admin_system.py` | 重新生成 Excel |

## 工作表一覽

| 工作表 | 用途 | 更新頻率 |
|--------|------|----------|
| **學生資料庫** | 學生、家長、課程、月費 | 有新報名時 |
| **收費記錄** | FPS / PayMe 轉帳記錄 | 每次收款 |
| **出席記錄** | 每日點名 | 每日放學後 |
| **排課表** | 每週課程安排 | 每學期 / 有變動時 |
| **課室使用表** | 課室時段分配 | 每週檢視 |
| **財務月結** | 收入、成本、淨利 | 每月底 |
| **學習進度** | 家長進度報告 | 每月 |
| **每日行政** | 營運者每日清單 | 每日 |
| **家長通訊** | 查詢、欠費、招生 | 每次通訊 |
| **導師資料** | 薪酬、合約、通知期 | 有變動時 |

## 實施順序

### Week 1（生存系統）
1. 從原老闆交接學生名單，填入「學生資料庫」
2. 建立 WhatsApp Business 官方帳號
3. 設定 FPS / PayMe 收款，開始記錄於「收費記錄」

### Week 2–3（效率系統）
4. 按實際課表更新「排課表」及「課室使用表」
5. 每日放學後更新「出席記錄」
6. 同步至 Google Calendar（可選）

### Month 1–2（專業形象）
7. 每月填寫「學習進度」，WhatsApp 發送家長
8. 每月底完成「財務月結」
9. 所有家長通訊記錄於「家長通訊」

## 每日行政流程（1–2 小時）

| 時段 | 任務 | 對應工作表 |
|------|------|------------|
| 早上 | 確認課表、通知導師、列出欠費 | 排課表、收費記錄 |
| 下午 | 點名、回覆家長、確保課室整潔 | 出席記錄、家長通訊 |
| 晚上 | 更新記錄、核對收費、規劃翌日 | 全部 |

## 上傳至 Google Sheets

1. 開啟 [Google Sheets](https://sheets.google.com)
2. 檔案 → 匯入 → 上傳 `俊才坊行政系統.xlsx`
3. 選擇「取代目前工作表」或「插入新工作表」
4. Extensions → Apps Script → 貼上 `google_apps_script.js`
5. 重新載入後，選單出現「俊才坊行政」

## 重新生成

cd jun-caifang/admin
