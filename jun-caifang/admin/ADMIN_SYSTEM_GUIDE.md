# 俊才坊行政系統 v2.0 使用指南

## 檔案

| 檔案 | 說明 |
|------|------|
| `output/俊才坊行政系統.xlsx` | 完整行政系統（12 個工作表） |
| `google_apps_script.js` | Google Sheets 自動化（8 項功能） |
| `build_admin_system.py` | 重新生成 Excel |

## 各工作表升級功能

### 儀表板（新增）
- 即時 KPI：在讀學生、欠費人數、本月實收/應收、待跟進通訊、今日課堂
- 待處理提醒清單
- 本月財務目標對照

### 學生資料庫
- 新增：英文姓名、課程類別、欠費金額、合約剩餘天數（自動）、學生狀態、轉介來源
- 自動統計：月費總額、在讀人數、欠費人數、平均 ARPU
- 條件格式：欠費標紅、合約 30 天內標黃

### 收費記錄
- 自動收據編號（R-YYMM001 格式）
- VLOOKUP 自動填入學生姓名及課程
- 自動計算差額及收款狀態（已付清/部分/未付）
- 本月實收/未收合計

### 出席記錄
- VLOOKUP 自動填入姓名及課程
- 月出席率統計表（按學號）
- 新增：補課安排、家長已通知欄

### 排課表
- 自動計算滿班率及預估月營收
- 候補人數欄
- 滿班 ≥100% 標紅、≥80% 標黃

### 課室使用表
- 各課室使用狀態（使用中/空閒）
- 空閒時段標綠
- 每呎產值估算

### 財務月結
- 自動計算總成本、月淨利、淨利率
- 目標達成率（對比 $82,000 月淨利目標）
- 年度累積淨利、平均月淨利

### 學習進度
- 自動生成 WhatsApp 進度訊息（複製貼上即可發送）
- 進步幅度自動計算（今月 vs 上月分數）
- 待發送標記

### 每日行政
- 完成率自動計算
- 每項任務關聯對應工作表
- 用時記錄欄

### 家長通訊
- 優先級（高/中/低）標色
- 逾期跟進自動標 ⚠️
- VLOOKUP 家長姓名

### 導師資料
- 自動統計負責學生數
- 合約剩餘天數及到期提醒
- 全職導師月薪合計

## Google Apps Script 功能

| 功能 | 說明 |
|------|------|
| 顯示儀表板摘要 | 彈出視窗顯示核心 KPI |
| 標記欠費學生 | 欠費/部分付款行標紅 |
| 統計本月營收 | 應收、實收、未收合計 |
| 列出今日課表 | 按星期顯示當日課程 |
| 生成繳費提醒 | 自動生成 WhatsApp 文字 |
| 生成學習進度訊息 | 複製未發送的進度報告 |
| 標記逾期家長通訊 | 逾期跟進標紅 |
| 標記導師合約到期 | 60 天內到期標黃 |
