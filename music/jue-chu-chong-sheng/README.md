# 《絕處．重生》Demo Track

Cantonese heavy metal demo (~2:45) with synthesized instrumental and Hong Kong male narration (zh-HK-WanLungNeural).

## Listen

**`jue-chu-chong-sheng.mp3`** — full mixed track

## Regenerate

```bash
pip install numpy scipy pydub edge-tts
python3 generate_song.py
```

Requires `ffmpeg` for MP3 export.

## Structure

| Time | Section |
|------|---------|
| 0:00–0:32 | 絕望 intro (slow metal ballad) |
| 0:32–1:18 | 煉獄 hell (aggressive double-kick metal) |
| 1:18–1:58 | 魂飛 soul flying (soaring lead) |
| 1:58–2:45 | 重生 rebirth (anthemic chorus) |
